# COLEMAN 4.20 — Plan once. Keep your CI experiment.

Compare CI prioritization policies, explore a bounded parameter grid and return
to the same experiment after the conversation ends. COLEMAN now connects its
native TCPCI engine to durable application workflows, a CLI and optional MCP
tools. Your configurations, progress, checkpoints and evidence belong to a local
workspace rather than a chat session.

## From a question to a reproducible experiment

An MCP-capable client can turn “compare Random and UCB, try three exploration
coefficients and two seeds” into an inspectable plan. COLEMAN validates the
registered history, explicit scheduling budget, objective and resource caps
before starting work. The same typed plan runs directly through the library or
CLI, without a model or API key.

The initial allowlist supports Random and UCB with RNFail, grid/zip enumeration,
explicit seeds and native ratio, fixed-time or test-count budgets. Three UCB
coefficients plus the Random baseline make **four configurations**; two seeds
make **eight logical trials**. Trials, physical retry attempts and independent
scientific observations remain separate quantities.

## Disconnect, reconnect and continue

Persistent job identities survive MCP client disconnection. Reconnect to inspect
progress, cancel work or explicitly resume compatible native checkpoints.
Completed trials retain their immutable artifacts; interrupted trials continue
their actual learned state and random generator state. Changed inputs, runtimes
or missing acknowledged checkpoints reject continuation with an explicit reason.

Completed reports publish last. Bounded summaries keep large rankings out of
model context, while immutable artifact handles provide verified downloads of
complete plans, reports, source receipts and native Parquet. Private executable
checkpoints remain local. Portable imports are read-only evidence.

## Keep tuning and evidence separate

An eligible protected workflow stops after training and validation. It freezes
the selected candidate, same-budget Random baseline, every selected seed's
learning state and the complete evaluation protocol before audited test access.
Earlier descriptive replay and imported outcomes retain their source exposure
across reconnects, re-encoding and cleanup.

This first integration exercises protected continuation on explicitly constructed
histories. Its one-family example correctly reports **insufficient evidence**
and retains Random as a conservative fallback. Original-source replay remains
descriptive; successful tuning does not grant empirical source admission or
establish that a policy is superior.

## Start with a complete example

The [durable experiments guide](https://jacksonpradolima.github.io/coleman/durable-experiments/)
includes installation, host registration, real SDK calls, CLI/library examples,
recovery, protected evaluation and artifact downloads. A public executable
example also checks library/MCP parity against the pinned Karaf source using an
approved pre-populated cache: **eight trials, 64 native build rows and 67 artifact
descriptors**, with the same mathematical digest through both interfaces.

This is an additive release. The original seven ephemeral MCP tools retain their
contracts; a trusted `--workspace` enables fourteen additional durable tools.
Existing native artifacts keep their meanings. The new workspace namespace
rejects unknown versions and provides no implicit checkpoint migration. Local
POSIX storage and trusted host registration are required; this is not a hosted
multi-user execution service.
