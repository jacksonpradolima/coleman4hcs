# Compatibility and release archive

Use release notes when upgrading, reproducing a pinned experiment or investigating
a compatibility change. For learning the current platform, start with
[concepts](concepts.md), [a first experiment](getting-started.md) or
[dataset workflows](datasets.md).

[GitHub releases](https://github.com/jacksonpradolima/coleman/releases) contain the
published distributions, digests and release descriptions. Installation examples
pin a verified artifact; their version is a reproducibility choice, not a claim
that the example is the latest release.

## Read compatibility notes

The navigation below this page groups historical notes by version. Those pages
record what was true for that delivery. Current source eligibility and unfinished
research are summarized in [evidence status](roadmap.md).

Maintainers should use [release preparation](releases.md) for packaging, validation
and publication, and [dependency security](dependency-security.md) for updates.
