# Measurement record API

Use `DomainRecord` when an extension needs raw observations with explicit units,
semantics, missingness and provenance. Native `fitness`/`cost` result columns
retain their original contract; they are not migrated implicitly into this one.

Read [versioned result records](../domain-results.md) for complete CI examples and
compatibility rules, then [evaluation](../evaluation-guide.md) for interpretation.
